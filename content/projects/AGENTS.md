# Project Case Study Instructions

Each featured project must demonstrate decisions and evidence, not only technologies.

- Cover objective, responsibilities, constraints, alternatives, decision rationale, implementation, trials, results, limitations, and future improvements.
- Distinguish individual contribution from team outcomes.
- Link technologies to concrete work rather than proficiency percentages or logo lists.
- Use measurable results only when their measurement method can be explained.
- Redact private company, client, repository, and production information.
- Keep repository and live links current or label them unavailable.
