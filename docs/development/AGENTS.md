# Development Documentation Instructions

Document repeatable local workflows from a clean checkout. Keep commands executable, safe, and consistent with package scripts and `scripts/` automation.

- State prerequisites and expected outcomes.
- Distinguish required commands from optional diagnostics.
- Keep setup idempotent and avoid machine-specific absolute paths.
- Link to the relevant local skill for agent procedures instead of duplicating it.
- Update instructions whenever toolchain or quality-gate commands change.
